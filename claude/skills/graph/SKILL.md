# graph — ざっくりCLIグラフ

数字の羅列や表では伝わりにくい「大小」「山谷」「符号」を、ASCIIグラフで一目で伝える。
**細かい作図はしない。ざっくり何が言いたいかが伝わることだけを狙う。**

## いつ描くか

次のいずれかに当てはまるなら、説明文を書く前に描く:

- **3件以上の数値を比較**する（店舗別・日別・項目別など）
- **推移や山谷**を語る（「8/13がピーク」「フラットで山がない」など）
- **プラスマイナスのある数値**を説明する（寄与度、前年差、増減）

逆に描かないほうがよいとき:

- 数値が2件以下、または「合計3,272名」のような単一の値 → 文章で足りる
- 正確な値の参照が目的（一覧性が要る） → 表のほうがよい
- 1つの回答にグラフを3つ以上入れない。**言いたいことが1つならグラフも1つ**

## 使い方

```bash
printf '8/13 迎え盆\t482\n8/15 送り盆\t506\n' \
  | python3 ~/.claude/skills/graph/scripts/chart.py bar -t "タイトル"
```

データ量が多いときは scratchpad に `.tsv` を書いてファイル指定でもよい。

```bash
python3 ~/.claude/skills/graph/scripts/chart.py line data.tsv -t "推移"
```

### モードの選び方

| モード | 使う場面 |
| --- | --- |
| `bar` | 項目どうしの大小比較、寄与度・内訳（マイナス値は自動でゼロ軸から左に伸びる） |
| `line` | 時系列の推移・山谷。**「形」を見せたいときは必ずこちら**（棒はゼロ起点なので山谷が潰れる） |

### 主なオプション

- `-t, --title` タイトル
- `-w, --width` 全体幅（既定72。Slack貼り付けもこの幅が無難）
- `--height` lineの高さ（既定12）
- `--sort asc|desc` 第1系列で並べ替え（寄与度の大きい順など）
- `--label-width` ラベル欄の最大幅（既定20、超えると切り詰め）
- `--zero` lineのy軸に0を含める

### データ形式

1行1レコード。区切りは **タブ > カンマ > 空白** の順で自動判定。
空白区切りのときは行末から続く数値を値とみなすので、ラベルに空白があってもよい。

```
ラベル<TAB>値                 # 単系列
ラベル<TAB>値1<TAB>値2        # 複数系列（█ と ▒ で塗り分け）
日付<TAB>実績<TAB>予測        # 1行目の2列目が数値でなければヘッダ＝系列名
```

- 欠損は空欄・`-`・`NA` で表す（棒を描かず `-` と表示）
- `1,234` のようなカンマ入り数値、`45%` の `%` は自動で除去

## 出力の扱い

- **色（ANSI）は使わない。** 回答にそのまま貼れるプレーンテキストで出す
- 回答に載せるときは**コードブロックで囲む**（等幅でないと桁が崩れる）
- グラフだけ貼って終わりにしない。**グラフの直後に「何が読み取れるか」を1〜2文で書く**
